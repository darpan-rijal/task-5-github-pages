# Task 5: Host a Static Website with GitHub Pages

## Project Overview

This project demonstrates how to create a static website using HTML and CSS, upload the source code to GitHub, and publish the website using GitHub Pages.

## Live Website

[View Live Website](https://darpan-rijal.github.io/task-5-github-pages/#)

## GitHub Repository

[View Source Code](https://github.com/darpan-rijal/task-5-github-pages.git)

## Technologies Used

* **HTML5:** Creates the structure and content of the website.
* **CSS3:** Controls the website's design and responsive layout.
* **Git:** Tracks changes to project files.
* **GitHub:** Stores the project's source code.
* **GitHub Pages:** Publishes the website online.

## Project Files

* `index.html` — Main webpage structure and content.
* `style.css` — Website styling, colors, layout, and responsive design.
* `README.md` — Project documentation.

## Deployment Steps

1. Created the website using HTML and CSS.
2. Initialized Git and committed the project files.
3. Created a GitHub repository and uploaded the files.
4. Enabled GitHub Pages from the `main` branch and root folder.
5. Opened and tested the published website.

## Learning Outcomes

Through this project, I learned how to create a simple static website, use Git and GitHub for version control, configure GitHub Pages, and deploy a website publicly for free.
