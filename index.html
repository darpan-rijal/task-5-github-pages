What Did I Build?

This project demonstrates how a static website can be created, stored in GitHub, and published on the internet.

HTML

HTML creates the structure and content of the website.

CSS

CSS controls colors, spacing, fonts, and layout.

GitHub Pages

GitHub Pages publishes the website online.

How It Gets Published

  1. Create the HTML and CSS files.
  2. Upload the files to a GitHub repository.
  3. Enable GitHub Pages in repository settings.
  4. Open the published website link.
